# Aviad workPA

אפליקציית אנדרואיד לניהול עבודות סאונד והגברה, חודש בחודשו.

- מסנכרנת את Google Calendar שבטלפון: כל אירוע עם "הגברה" או "סאונד" בכותרת נכנס אוטומטית
- לכל עבודה: מעסיק, סכום, שולם / ממתין, הערות
- סיכום חודשי: מספר עבודות, סה״כ, שולם, ממתין
- דוח PDF חודשי לכל מעסיק – שמירה או שליחה (וואטסאפ, מייל)
- עבודה שנוספת באפליקציה נרשמת גם ביומן

## הורדה

ה-APK נבנה אוטומטית בכל עדכון. הקובץ האחרון נמצא תחת **Releases → latest → Aviad-workPA.apk**.
